**All platform exercises must include:**
1. **Platform-specific objectives** - What feature/workflow is being practiced
2. **Step-by-step UI walkthrough** - Screenshots, click paths, field descriptions
3. **REST API examples** - PowerShell/curl commands for automation
4. **CISSP domain mapping** - Which exam topics this covers
5. **Interview talking points** - How to discuss this experience in interviews
6. **Troubleshooting section** - Common issues and resolutions
7. **Time estimate** - Expected completion time
8. **Prerequisites** - What must be set up first
