# R-EX-047 — Ansible pipeline risk

**Domain 8**

## Task
List three risks of a compromised provisioning host and one control each.

## Answer key
1) Mass misconfig → CTL-ANSIBLE-ACCESS 2) Secret vault theft → vault + short-lived creds 3) Supply of malicious roles → signed roles / PR review (CTL-CHANGE-MGMT).
