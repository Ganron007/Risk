# R-EX-039 — Chain of custody checklist

**Domain 7**  
**Assets:** AST-030, AST-032

## Task
List CoC fields required before an examiner opens a case in DFIR-Nexus.

## Answer key
Case ID, custodian, hash of evidence, acquisition time, storage location, access log, HITL approval password set, no AI DRAFT auto-promote (CTL-HITL / CTL-COC).
